# @ichiran/grammar

Japanese grammar pattern detection using GiNZA's dependency parsing and morphological analysis.

## Overview

This package identifies Japanese grammar patterns in text by matching against linguistic rules. Unlike regex-based approaches that match surface forms, rules here operate on **parsed linguistic structure** — dependency relations, POS tags, and inflection forms.

## Architecture

```
Input Text → GiNZA (Python) → Typed Tokens → Rule Matching → Grammar Hits
```

### GiNZA Integration

A Python subprocess runs GiNZA (spaCy-based Japanese NLP) and streams parsed tokens as JSON. Each token includes:

- **pos** / **dep**: Universal Dependencies labels
- **lemma**: dictionary form
- **conjugationClass** / **inflectionForm**: parsed from GiNZA's `Inflection` field (e.g. `五段-カ行`, `連用形-イ音便`)
- **head**: dependency head index

Types are **corpus-derived** — generated by running GiNZA on 15k Bunpro sentences and collecting all observed values. No hardcoded enums.

### Rule DSL

Rules are authored as **linguistic patterns**, not string patterns:

```typescript
linguisticRule('-ようとしない', 'JLPT3', (r) => {
  const suru = r.verb({ lemma: 'する' });
  const nai = r.aux({ lemma: 'ない' });
  r.auxOf(suru, nai);                           // dependency: ない → する (aux)
  
  const vol = r.verb({ inflectionForm: '意志推量形' });  // volitional form
  r.headChild(suru, vol, 'advcl');              // dependency: volitional → する (advcl)
  
  const to = r.particle('と');
  r.caseMarker(vol, to);                        // dependency: と → volitional (case)
  
  r.capture(vol);
});
```

Rules express:
- Token conditions (POS, lemma, inflection)
- Dependency edges between tokens
- Surface order constraints

### Matching

Rules compile to a trigger-indexed matcher:
1. Extract triggers (lemma/text literals) from rules
2. Build dispatch map: trigger → candidate rules
3. On input, collect tokens' lemmas/texts, lookup candidates, run full match

## Usage

```typescript
import { GrammarEngine, SELECTED_RULES } from '@ichiran/grammar';

const engine = await GrammarEngine.create(SELECTED_RULES);
const hits = await engine.match('彼は絶対に諦めようとしない。');
// → [{ ruleId: '-ようとしない', level: 'JLPT3', span: { start: 9, end: 15 } }]

await engine.close();
```

## Regenerating Types

When GiNZA or the corpus changes:

```bash
bun run scripts/generate-ginza-types.ts
```

This scans Bunpro sentences with GiNZA and generates `src/ginza/generated.ts` with:
- `GinzaPOS`, `GinzaDep` — observed POS/dependency labels
- `GinzaConjugationClass`, `GinzaInflectionForm` — parsed from `Inflection` strings
- Helper functions for type-safe inflection checks
