# Ichiran CLI

The CLI preserves the historical analyzer modes while running entirely from a
verified packed release. It does not connect to PostgreSQL.

## Setup

Build the product packages and point the Node adapter at a release directory:

```bash
bun run build
export ICHIRAN_PACK_DIR=/absolute/path/to/analyzer-release
```

The directory must contain `manifest.json`, `hot.bin.gz`, and `details.bin.gz`.
Checksums and installed sizes are verified before the runtime opens.

## Usage

```bash
ichiran-cli [options] [input]
```

From this repository, the equivalent command is `bun run cli -- [options] [input]`.

```bash
ichiran-cli "こんにちは"
# konnichiwa

ichiran-cli -i "今日はいい天気です"
# romanization followed by dictionary information

ichiran-cli -f "食べました"
# legacy-compatible full analysis JSON

ichiran-cli -f -l 5 "みんな土足でおいで"
# up to five segmentation paths
```

## Options

```text
-h, --help              print help text
-i, --with-info         print dictionary information with romanization
-f, --full              print full analysis as JSON
-l, --limit <number>    limit segmentation paths (default 1; used with --full)
-e, --eval <expression> reserved for compatibility; unsupported
-V, --version           print the CLI version
```

Input is the remaining positional arguments joined with spaces. The CLI applies the
historical punctuation normalization. Errors go to stderr and return a non-zero exit
status.

## Compatibility

Simple mode, info mode, full JSON nesting, segmentation alternatives, integer scores,
dictionary details, compounds, counters, suffixes, conjugations, and romanization are
part of the parity contract. Full JSON is generated by the same `@ichiran/core`
runtime used in the browser; the CLI does not maintain a second analyzer.

Grammar analysis is not a CLI mode. The separate experimental grammar package is
outside this milestone.
